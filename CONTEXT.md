| Термин | Значение | Не заменять на |
|---|---|---|
| Diva Nails | Бренд ногтевой студии в Чебоксарах. | Отдельное имя конструктора. |
| Конструктор маникюра | Место, где посетитель собирает и меняет маникюр перед записью. | Игра, виртуальный салон. |
| Дизайн | Весь выбранный маникюр: рука, тон кожи, форма, длина и оформление каждого ногтя. | Узор, картинка. |
| Дизайн месяца | Стартовое готовое предложение; до получения материалов студии используется временный сезонный вариант. | Работа мастера, если авторство не подтверждено. |
| Оттенок | Цвет покрытия с подписью бренда и номера; временно — с кодом и названием. | Тон кожи. |
| Тон кожи | Один из четырёх вариантов цвета кожи руки. | Оттенок лака. |
| Эффект покрытия | Вид покрытия: например, глянец, матовое или хром. | Узор, декор. |
| Узор | Рисунок на ногте: например, френч, мрамор или полоски. | Весь дизайн. |
| Декор | Стразы и наклейки, которые можно расположить на ногте. | Эффект покрытия. |
| Принт | Своя картинка, размещённая непосредственно на ногте. | Референс. |
| Референс | Приложенная картинка с пожеланием «хочу похоже», которую видит мастер на карточке. | Принт, обещание точного повторения. |
| Карточка-бриф | Сохранённое изображение маникюра с описанием для мастера. | Подтверждение записи, чек. |
| Запись | Выбор времени онлайн или обращение в студию для согласования визита. | Сохранение дизайна. |
| «Уточняется» | Явная отметка сведений или материалов, ожидаемых от студии. | Подтверждено, в наличии. |
