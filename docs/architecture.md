# Архитектура Diva Nails

Статический сайт на Vite 7, Preact 10, signals и TypeScript. Серверной части, базы данных и загрузки пользовательских файлов на сервер нет. Публичный base — `/diva_nails/`; адрес для ссылок и SEO берётся из `data/studio.json` (`siteUrl`).

## Входы и отображение

`vite.config.ts` собирает три HTML-входа: `index.html`, `d/index.html`, `privacy/index.html`. Главная пререндерится при сборке. `src/main.tsx` сначала гидратирует её с дизайном месяца, затем вызывает `bootFromLocation`: это сохраняет совпадение стартовой разметки и состояния. Страница `d/` рисуется на клиенте; политика конфиденциальности имеет отдельный HTML-вход.

`src/App.tsx` соединяет шапку, конструктор, секции, подвал, один `BookingHost` и JSON-LD. `src/constructor/` отвечает за SVG-руку, геометрию, покрытия и инструменты. `src/motion/` управляет лампой, движением и наклоном с учётом reduced motion. Секции взаимодействуют с конструктором через store, с записью — через `booking.open()`.

## Данные студии и медиа

`data/*.json` — источник содержимого; `src/data/*.ts` типизируют и экспортируют его. Неизвестные цены, реквизиты или условия остаются `null` и отображаются через `Pending`/`Maybe`. Временные палитры, декор, пресеты и фотографии отмечаются как временные; перечень замен — `docs/ЗАМЕНИТЬ.md`. Факты, отзывы и обещания не дополняются догадками.

Доступность эффектов задаётся `data/palette.json.effects` через `availableEffects()`. Порядок `EFFECTS` в модели — отдельный контракт кодека, а не список доступных услуг. `id` и `idx` оттенков/декора стабильны; индексы не переиспользуются. Удалённые оттенки сохраняются в `retired` для восстановления старых ссылок ближайшим цветом.

`npm run media` преобразует исходники `media-src/` в AVIF/WebP в `public/media/` и генерирует `src/media/manifest.ts`; компоненты используют этот манифест. Шрифты обслуживаются самим сайтом.

## Состояние и ссылка

`src/state/design.ts` описывает Design v1: руку, тон, форму, длину и пять ногтей. `normalizeDesign` ограничивает декор тремя элементами на ноготь, привязывает координаты к сетке 16×16, размеры к фиксированному набору и поворот к шагу 45°. Мужской режим дополнительно ограничивает форму, длину и покрытия.

`src/state/store.ts` — единственный store приложения; `createDesignStore` позволяет изолированные экземпляры. История содержит дизайн, принты и референс, хранит до 50 шагов. Движения с одинаковой меткой объединяются до `endGesture()`; его вызывают при завершении или отмене жеста. `load` очищает принты, сохраняя референс; `reset` очищает оба.

`src/state/link.ts` кодирует дизайн в `#d=`; порядок перечислений является частью v1. `boot.ts` читает ссылку после гидратации и обновляет URL через `replaceState`. Битая или чужая версия открывает дизайн месяца с предупреждением. Пропавший оттенок заменяется ближайшим, если известен его прежний цвет. Ссылка для передачи строится как `siteUrl + d/#d=…`.

## Локальные файлы, карточка и внешние сервисы

`src/constructor/tools/image.ts` проверяет картинку, при необходимости уменьшает до 1600 px и создаёт `blob:` URL. `Print` и `Reference` живут только в памяти текущей страницы, включая историю; в ссылку и постоянное хранилище они не записываются. После перезагрузки картинку нужно выбрать снова.

`src/card/index.ts` по нажатию лениво загружает сборщик и лист сохранения. `build.ts` соединяет SVG-руку, текст, QR, референс и локальные шрифты в PNG 1080×1920 через canvas. Картинки видны в PNG, но QR содержит только дизайн без них. Сохранение идёт через Web Share, скачивание или просмотр изображения; отправку выбирает пользователь.

`src/booking/` готовит текст, копирует его в буфер и открывает Telegram. Сайт сам не отправляет сообщение и не создаёт запись. Yclients открывается только при наличии URL в данных; иначе показана подсказка обратиться в Telegram. Контакты лениво загружают iframe Яндекс Карт, при сбое оставляют адрес и ссылку.

`src/analytics.ts` подключает Яндекс Метрику только при ненулевом `metrikaId`. Уведомление о cookies отображается при включённой аналитике; localStorage хранит факт его закрытия, а не дизайн. SessionStorage используется для состояния наклона. Ключи генерации изображений не относятся к клиентскому приложению и не должны попадать в код, сборку или публичную копию.

## Проверки и публичная копия

`npm run check` объединяет типы, линтер, unit-тесты, production-сборку и бюджет. `npm run e2e` запускает `scripts/e2e.mjs` с `PW_DISABLE_TS_ESM=1`: это обязательный обход несовместимости ESM-загрузчика Playwright 1.52 с Node 24. E2E работает с preview на 4173, установленным WebKit и системным Chrome. Полные команды запуска — в AGENTS.md.

`exportPublic()` в `scripts/export-public.mjs` принимает новую пустую папку либо собственную маркированную выгрузку. Маркер `.diva-nails-export.json` версии 2 содержит источник, список файлов и SHA-256. До любых записей и удалений проверяются владение, Git и байты всех прежних файлов; пути канонизируются через `realpathSync.native`, включая Windows 8.3. Чужая, изменённая или старая выгрузка отклоняется. Источник должен иметь чистые отслеживаемые файлы; выгружаются отслеживаемые публичные файлы, создаётся отдельный репозиторий и коммит. Рабочие материалы Autopilot/Impeccable и память агентов исключаются.

Экспорт не выполняет push. Публикация допускается только по отдельному слову пользователя: push в `master` публичного репозитория запускает `.github/workflows/pages.yml`, который выполняет `npm ci`, `npm run check` и выкладывает `dist/` на GitHub Pages.
