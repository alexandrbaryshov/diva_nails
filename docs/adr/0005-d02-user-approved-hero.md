## Контекст

D02: component-review capture не принимает первый экран на Vite/TSX; принудительное закрытие hero отказано. Пользователь 2026-10-30 принял экран словом «принимаю». Спецификация фиксирует соответствие макету 85%, тёмные кнопки по выбору «1б» и временный оттенок безымянного ногтя.

## Решение

Считать первый экран принятым пользователем, сохраняя формально открытый гейт hero. Продолжать sections, motion и responsive по их правилам без build-phase advance, со снимками для финального ревью. Первый экран не менять без пользователя.

## Почему

Основание продолжения — явная приёмка пользователя при документированном ограничении инструмента. Спецификация запрещает менять требования брифа ради прохождения гейта.

## Последствия

Приёмка пользователя и статус автоматического гейта остаются разными фактами; закрытие гейта не заявляется. Последующие секции должны следовать визуальному языку принятого экрана. Финальное ревью требует снимков результата.
